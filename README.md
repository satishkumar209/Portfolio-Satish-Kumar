# Satish Kumar — Cinematic Portfolio

## Run locally
1. Install Node.js (LTS) if it is not already installed.
2. Extract this ZIP file.
3. Open the extracted `satish-cinematic-portfolio` folder in VS Code.
4. Open Terminal in VS Code and run:

   npm install
   npm run dev

5. Open the local address printed in the terminal (usually http://localhost:5173).

## Your intro video
Your uploaded video is already copied to `public/satish-intro.mp4` and is used in the hero section as a muted, autoplaying, looping background-style video.

To replace it later, put another MP4 in the `public` folder and name it `satish-intro.mp4`.
